zephyra

Tweaks for rootless jailbreaks such as Dopamine. Each tweak adds its own settings app to the home screen.

Add to Sileo

Or add this source manually: https://zephyranthess.github.io/repo/

  • CarCast · iOS 17+
    Run any app on CarPlay, with per-app settings and iPad layouts.
  • LineFix · iOS 15+
    Makes a broken vertical screen line much less visible.
  • SpeedBoost · iOS 15+
    Faster home screen animations, fewer heavy background services.
